## Namen projekta

Izdelava spletne aplikacije za podporo šolskemu delu na daljavo.

Sistem bo omogočal tri uporabniške poglede:
- administrator
- učitelj
- učenec

## Tehnologije

- HTML
- CSS
- JavaScript
- Node.js
- Express
- MariaDB
- Docker
- Docker Compose
- Nginx
- Git in GitHub

## Struktura projekta

- `aplikacija/` – izvorna koda spletne aplikacije
- `dokumentacija/` – analiza zahtev, ER diagram, wireframe in poročila
- `baza/` – datoteke in skripte podatkovne baze
- `nginx/` – konfiguracija spletnega strežnika
- `backup/` – skripte za varnostne kopije
